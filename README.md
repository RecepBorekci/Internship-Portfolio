
# Internship Portfolio Website

This is a personal portfolio website developed using **React.js** during my frontend internship at **Orta Anadolu** in **July 2023**. The goal was to create a modern, responsive, and dynamic portfolio site that showcases my projects, skills, and development style.

🌐 **Live Site**: [recepborekci.com](https://recepborekci.com)

---

## 📌 Project Overview

- 📅 **Internship Duration**: 3 July – 28 July 2023 (20 working days)  
- 🏢 **Company**: Orta Anadolu  
- 💼 **Role**: Front-End Intern  

During this internship, I built this portfolio project from scratch, implementing:
- A responsive and mobile-friendly layout
- Component-based architecture with reusability in mind
- Smooth navigation and visual styling using both Bootstrap and Material-UI
- Production-ready deployment

## 🔧 Installation & Development

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/recepborekci/Internship-Portfolio.git

# Navigate into the project folder
cd Internship-Portfolio

# Install dependencies
npm install

# Start the development server
npm start
````

Open your browser and go to `http://localhost:3000` to view the site.

---

## 📦 Build & Deployment

To build the production version of the project:

```bash
npm run build
```

This will generate a `build/` folder with optimized static files for deployment.
